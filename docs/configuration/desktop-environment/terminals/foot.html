foot

This guide shows how to build and install foot, a fast and lightweight Wayland terminal, on Vind Linux. foot is the default terminal of dwl. Like dwl, it is not part of lambda, so you compile it yourself.

1. Requirements

foot needs a Wayland session to run, so set up dwl first. The libraries it builds against (pixman, wayland, xkbcommon, fontconfig, freetype) are already present once wlroots is installed. Two of its own libraries, tllist and fcft, are downloaded and built automatically during the build, so the machine needs network access and git.

You also need at least one monospace font installed, and a UTF-8 locale (Vind sets LANG=C.UTF-8 in /etc/profile).

2. Build and install

cd /source
git clone https://codeberg.org/dnkl/foot.git
cd foot
export PKG_CONFIG_PATH=$PKG_CONFIG_PATH:/usr/lib64/pkgconfig
meson setup bld/release --buildtype=release --prefix=/usr -Dterminfo-base-name=foot-extra
ninja -C bld/release
ninja -C bld/release install

The PKG_CONFIG_PATH line is needed for the same reason as in the dwl guide: without it, meson stops with Dependency "pixman-1" not found. If you already made it permanent in /etc/profile, you can skip it.

-Dterminfo-base-name=foot-extra makes foot use the foot terminfo that already ships with ncurses, and installs its own extra definitions under the name foot-extra, so the two never overwrite each other.

While configuring you will see Grapheme clustering: NO and a few found: NO lines for optional libraries (libutf8proc, harfbuzz, systemd). They only disable optional features and can be ignored.

3. Run foot

Start dwl and press Alt+Shift+Enter. You can also launch it from any terminal inside the session: 

foot

If foot complains about its terminfo, start it with a generic one instead: 

foot --term xterm-256color

Running foot outside a Wayland session fails, because there is no compositor to connect to.
