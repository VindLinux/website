mesa

mesa provides the graphics libraries and drivers (OpenGL, Vulkan, EGL, GBM) that Wayland compositors and many applications rely on. wlroots, and therefore dwl, depends on it, so it is installed automatically. What you need to choose yourself is which GPU driver to build.

1. Choose your GPU driver

GPU drivers are optional attrs of the mesa package, and none is enabled by default. Pick the one that matches your graphics hardware:

intel for Intel graphics, and amdgpu for AMD graphics. Without a driver for your GPU, graphics fall back to software rendering, which is much slower. Enabling amdgpu requires LLVM with AMD support, so the first build takes noticeably longer.

2. Enable the attrs

Add the driver to /etc/lambda/package.compattrs. For example, for both Intel and AMD: 

mesa intel amdgpu

Or, to enable it for every package, add this to /etc/lambda/make.conf: 

COMP_ATTRS="intel amdgpu"

Use only the attrs that apply to your machine. Then rebuild the packages: 

lambda reconcile

To confirm, run lambda info mesa and check that the driver now appears under the enabled compattrs.

3. Virtual machines

In a VM without graphics acceleration (such as stdvga), none of these drivers applies, and dwl has to use the software renderer instead. See the dwl page for the pixman setting.
