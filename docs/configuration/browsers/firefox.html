Firefox

This guide shows how to install Firefox on Vind Linux. Firefox is not packaged for lambda, so it is installed as a Flatpak from Flathub: the application is downloaded already compiled and nothing has to be built from source. Run the commands as your normal user.

1. Requirements

Set up Flatpak first, including the D-Bus session, the XDG_DATA_DIRS variable and the Flathub repository. Firefox is a graphical application, so you also need a working dwl session.

Firefox and its runtime take between 1 and 2 GB, so check the free space in your home: 

df -h /home

2. Install Firefox

flatpak --user install flathub org.mozilla.firefox

Flatpak asks to confirm the runtime (org.freedesktop.Platform) and then the application. Add -y to answer yes to all questions. Check that it was installed: 

flatpak --user list

3. Run Firefox

Inside the dwl session (opened with start-dwl), open a terminal with Alt+Shift+Enter and run: 

flatpak run org.mozilla.firefox

In a VM without graphics acceleration Firefox uses software rendering and is slow, but it works. On real hardware it runs normally.

4. Optional: a shorter command

Vind has no launcher, so typing the full Flatpak command every time gets tedious. As root, create a small wrapper: 

cat > /usr/bin/firefox <<'EOF'
#!/bin/sh
exec flatpak run org.mozilla.firefox "$@"
EOF

chmod +x /usr/bin/firefox

Now firefox starts it from any terminal, and accepts arguments such as an address: 

firefox https://example.com

The wrapper runs flatpak run as whichever user calls it, so Firefox must be installed for that user.

5. Update and remove

flatpak --user update
flatpak --user uninstall org.mozilla.firefox
flatpak --user uninstall --unused

Your profile is kept in ~/.var/app/org.mozilla.firefox, so it survives updates. It is not removed by uninstall unless you add --delete-data.

6. Troubleshooting

Cannot autolaunch D-Bus without X11 $DISPLAY, or Firefox opens and closes immediately: the D-Bus session is not reachable. Follow the troubleshooting section of the Flatpak guide and check: 

sv status dbus-session
echo "$DBUS_SESSION_BUS_ADDRESS"

bwrap: No permissions to create new namespace: user namespaces are disabled. Redo the kernel checks in the Flatpak guide.

Firefox opens through XWayland or looks blurry: force it to use Wayland natively. 

flatpak override --user --env=MOZ_ENABLE_WAYLAND=1 org.mozilla.firefox

Letters appear as empty boxes or the wrong font is used: no fonts are installed for it to use. Install some with lambda, for example lambda mutate append jetbrains-mono-fonts, as in the foot guide.
