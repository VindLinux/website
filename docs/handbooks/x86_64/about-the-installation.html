About the Installation

Next ›

This is the quick version: partition, install the base system, configure it, make it bootable.

If you want the why behind any step, the from-scratch build guide goes into a lot more detail — this handbook is meant to be followed, not studied.

What you'll need

The Vind Linux live ISO, a target disk you don't mind wiping, and a working internet connection inside the live environment (the base system and packages are downloaded during the install).

How this handbook is organized

Each chapter builds on the last, in order: partitioning and filesystems first, then the base system and chroot, the toolchain, package set, basic configuration, networking, and finally getting the system to actually boot. Use the Next and Prev links above to move through it.
