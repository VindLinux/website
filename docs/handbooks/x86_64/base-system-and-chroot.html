4.1. Download and extract the base system

cd /mnt/vind
wget https://github.com/VindLinux/vindlinux/releases/download/0.4/vind-base-0.4-x86_64.tar.xz
tar -xf vind-base-0.3-x86_64.tar.xz
rm vind-base-0.3-x86_64.tar.xz

4.2. Mount the pseudo filesystems and chroot in

mount --bind /dev  /mnt/vind/dev
mount -t proc proc /mnt/vind/proc
mount -t sysfs sys  /mnt/vind/sys
mount -t tmpfs tmpfs /mnt/vind/run

chroot /mnt/vind /bin/dash

(/bin/ash works too — it's got a few more built-in features, so that's the personal pick around here.)
