Chapter 2

Networking in the Live Environment

Next ›

The base system and packages are downloaded during the install, so the live environment needs a working internet connection before you start.

Running in a VM? You can skip this chapter — the virtual NIC is normally brought up for you. Go straight to the Next link.

On real hardware, wired and wireless both need dbus running first, and wireless also needs iwd.

2.1. Start D-Bus

mkdir -p /run/dbus
dbus-daemon --system --fork
ln -sf /run/dbus /var/run/dbus

2.2. Start iwd (wireless only)

Skip this section and the next if you're on a wired connection.

/usr/libexec/iwd &

2.3. Connect to a Wi-Fi network (wireless only)

iwctl
[iwd]# device list
[iwd]# station <device> scan
[iwd]# station <device> get-networks
[iwd]# station <device> connect <SSID>
[iwd]# exit

2.4. Get an IP address and test

iwd only handles the link and authentication, so wired and wireless both need dhcpcd to get an address: 

ip link   # find your interface name, e.g. enp0s3, wlan0
dhcpcd <interface-name>
ping -c 1 1.1.1.1

If the ping answers, you're online and can move on to partitioning.
